How it works

A full 2D game studio that runs entirely in the browser — powered by the Phaser 3 engine and an optional AI assistant.

🎨

Design everything in-browser

Upload your characters, design sprites, and add sounds. No external tools, no setup — it all lives in the tab.

🤖

AI assistant (optional)

Add an Anthropic API key to unlock AI chat and AI sprite generation. Describe what you want and it helps build it.

⚡

Built on Phaser 3 + JavaScript

The studio runs 100% in JavaScript with the battle-tested Phaser 3 engine — smooth, fast, and the browser's home turf.

🚀

Publish from the tab

When your game is ready, publish it straight from the browser. No accounts to create to get started.

What you can build

Phaser 3 supports a wide range of 2D genres out of the box.

📖 Visual novelsDialogue boxes, character art, click to advance.
🔎 Point-and-click adventuresExplore scenes, click hotspots, solve puzzles.
⚔️ Turn-based RPGsMenus, stats, and battle systems.
🌿 Choose-your-own-adventureBranching choices that change the story.

Just ask the AI assistant "make me a visual novel with dialogue and choices" and it'll build it.
